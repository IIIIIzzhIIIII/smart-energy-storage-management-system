# 一键运行版构建说明

本文件面向开发者，说明如何从源码生成 `EnergyMonitor-v1.1.0-win64.zip`。

## 1. 构建环境

| 工具 | 版本要求 | 说明 |
|------|----------|------|
| JDK | 17 | 必须含 `jlink.exe`、`jar.exe` |
| Maven | 3.9+ | 脚本找不到时会自动下载到 `.tools/` |
| Node.js | 18+ | 构建 Vue 前端 |
| Python | 3.9~3.13 | 需能导入项目依赖 |
| .NET Framework | 4.x | 使用系统自带 `csc.exe` 编译启动器 |

Python 依赖：

```powershell
D:\Python\python.exe -m pip install -r python-ems\requirements-build.txt
```

## 2. 一键构建

在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-release.ps1
```

指定 Python 解释器或跳过 Python：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-release.ps1 -PythonExe D:\Python\python.exe
powershell -ExecutionPolicy Bypass -File scripts\build-release.ps1 -SkipPython
```

产物：

```
dist\EnergyMonitor-v1.1.0-win64.zip
dist\EnergyMonitor-v1.1.0-win64.zip.sha256
```

`-SkipPython` 生成 `*-basic.zip`，不含预测/DRO。

## 3. 脚本做了什么

1. `npm run build` 构建前端；
2. `mvn -DskipTests clean package` 打包 Spring Boot；
3. 用 `jar uf` 把 `frontend/dist` 注入 jar 根目录（Spring Boot 直接提供静态页面）；
4. PyInstaller 按 `python-ems.spec` 生成 `dist/python-ems/`；
5. `jlink` 生成精简 JRE；
6. `csc` 编译 `launcher/EnergyMonitorLauncher.cs`；
7. 组装 `build/release/EnergyMonitor/` 并压缩、计算 SHA256。

## 4. 发布版关键设计

- **单端口**：页面与 API 都在 8082，避免前端跨域与 Nginx 依赖；
- **H2 文件库**：`jdbc:h2:file:./data/energy_monitor;MODE=MySQL;...`，首次启动执行 `db/h2-schema.sql` + `db/h2-data.sql`；
- **双数据库兼容**：分页方言按驱动自动选择；电量统计用 `MIN/MAX/COUNT` 替代 MySQL 的 `TIMESTAMPDIFF`；
- **SPA 刷新**：`SpaController` 把已知 Vue 路由 forward 到 `index.html`；
- **健康检查**：`/api/health` 免登录，启动器据此判断就绪；
- **DRO 自愈**：后端每 15 秒轮询，Python 晚启动也会自动恢复；
- **Python 冻结**：`server_entry.py` 直接传 app 对象给 uvicorn，避免冻结后字符串导入失败。

## 6. 常见构建问题

### PyInstaller 报缺少模块

在 `python-ems.spec` 的 `hiddenimports` 中补充，或先确认开发态 `python server_entry.py` 可启动。

### jlink 报模块不存在

不同 JDK 的模块名略有差异，可先用 `java --list-modules` 查看；本项目只依赖标准模块。

### 压缩包过大

- 确认没有把 `python-ems/build`、`node_modules` 打进包；
- PyInstaller 已排除 matplotlib/tkinter/IPython/pytest；
- 完整版约 200~400 MB，基础版约 80~120 MB。
