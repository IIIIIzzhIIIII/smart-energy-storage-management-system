# Windows 桌面版使用说明

## 1. 系统要求

- Windows 10 / 11，64 位
- 4 GB 以上内存，约 1 GB 可用磁盘空间
- 8082（Web 与 API）和 8000（预测服务）端口空闲
- 无需安装 Java、MySQL、Node.js 或 Python

## 2. 获取与启动

请从 [Releases](https://github.com/IIIIIzzhIIIII/smart-energy-storage-management-system/releases/latest) 下载发行包，不要使用仓库首页的 `Code → Download ZIP`，该入口仅提供源码。

1. 下载 `EnergyMonitor-v1.1.1-win64.zip`；
2. 完整解压到本地目录，建议 `D:\EnergyMonitor`；
3. 确认 `EnergyMonitor.exe` 位于解压目录的**根目录**，与 `app`、`runtime` 文件夹同级；
4. 双击 `EnergyMonitor.exe`；
5. 首次启动会创建 H2 数据库并生成示例历史数据，通常需要 30~90 秒；
6. 状态显示“服务已就绪”后浏览器会自动打开 `http://127.0.0.1:8082`，也可手动访问；
7. 使用默认账号登录。

| 账号 | 密码 | 角色 |
|------|------|------|
| admin | 123456 | 管理员 |
| dispatcher | 123456 | 调度员 |
| user | 123456 | 普通用户 |
| viewer | 123456 | 只读用户 |

> 关闭启动器窗口会同时停止 Java 与 Python 服务。

## 3. 目录说明

```text
EnergyMonitor\
├── EnergyMonitor.exe        # 桌面启动器（根目录）
├── app\
│   └── energy-monitor.jar   # 后端服务（已内置前端页面）
├── runtime\                 # 精简 JRE 17
├── python\                  # 预测与 DRO 服务
├── data\                    # H2 数据库文件
├── logs\                    # 运行日志
├── docs\                    # 文档
├── README.md
└── 使用说明.md
```

## 4. 数据备份与迁移

- 业务数据保存在 `data\energy_monitor.mv.db`；
- 备份：关闭程序后复制整个 `data` 目录；
- 迁移：将整个 `EnergyMonitor` 目录复制到新机器，并保留 `data`；
- 重置示例数据：关闭程序，删除 `data` 目录后重新启动。

## 5. 常见问题

### 5.1 双击后没有反应

- 检查安全软件是否拦截，必要时将程序目录加入白名单；
- 确认解压完整，`runtime\bin\java.exe` 与 `app\energy-monitor.jar` 存在；
- 查看 `logs\backend.log`。

### 5.2 提示端口被占用

```powershell
netstat -ano | findstr :8082
netstat -ano | findstr :8000
```

结束占用进程或重启机器后重试。8082 被其他程序占用时，系统无法启动。

### 5.3 页面可打开但 DRO 计划获取失败

- 预测服务可能仍在启动，等待 15~30 秒后刷新；
- 查看 `logs\python.log`；
- 若 `python` 目录缺失，基础监控功能仍可使用，但预测与 DRO 不可用。

### 5.4 启动超时

- 首次启动生成历史数据较慢，机械硬盘可能需要 1~2 分钟；
- 检查 Windows Defender 或第三方安全软件是否拦截 `java.exe`、`python-ems.exe`；
- 查看 `logs\backend.log` 中的异常信息。

### 5.5 接入真实温湿度传感器

桌面版默认使用模拟采集。需要接入真实串口时，请使用源码运行，并在 `application-release.yml` 中将 `safety.mode` 改为 `real`，配置 `serial-port` 与波特率。

## 6. 安全说明

- 服务默认仅监听本机回环地址，不对外网开放；
- 发行包内置 JWT 密钥仅用于本地运行，部署前必须替换；
- 如需公网访问，请改用 MySQL、修改默认密码、替换 JWT 密钥，并增加 HTTPS 与反向代理。
