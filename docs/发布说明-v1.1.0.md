# v1.1.0 一键运行版

## 下载

- `EnergyMonitor-v1.1.0-win64.zip`：完整版，内置 JRE + H2 + Python 预测服务（推荐）
- `EnergyMonitor-v1.1.0-win64.zip.sha256`：校验文件

> 仅支持 Windows 10/11 64 位，无需安装 Java / MySQL / Node.js / Python。

## 快速开始

1. 下载并**完整解压**到不含中文、空格的目录（如 `D:\EnergyMonitor`）；
2. 双击 `EnergyMonitor.exe`；
3. 等待首次初始化（30~90 秒），浏览器会自动打开 `http://127.0.0.1:8082`；
4. 使用 `admin / 123456` 登录。

关闭启动器窗口即停止服务。数据保存在 `data\energy_monitor.mv.db`，迁移时复制整个 `data` 目录。

## 本版内容

- 新增 Windows 一键启动器：单实例、健康检查、自动打开浏览器、日志目录
- 新增 release 配置：H2 文件数据库、单端口 8082、前端静态资源内置
- 新增 H2 建表与种子数据（含安全检测模块最终表结构）
- 新增 `/api/health` 健康检查（免登录）
- 新增 Vue History 路由刷新回退，解决刷新 404
- 数据库兼容改造：分页方言自动识别、电量统计去除 MySQL 专有函数
- 首次启动自动生成 3 天历史数据，后续启动自动跳过
- Python 服务支持 PyInstaller 冻结；DRO 计划改为 15 秒自愈轮询
- 补充一键运行版构建/使用文档，清理敏感本机路径

## 已知限制

- 发布版安全检测默认模拟模式，未连接真实串口；
- 内置 JWT 密钥仅用于本地演示，请勿直接暴露到公网；
- 首次启动生成历史数据较慢，机械硬盘可能需要 1~2 分钟。
