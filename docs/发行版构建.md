# Windows 发行版构建

本文面向开发者，说明如何从源码生成 `EnergyMonitor-v1.1.1-win64.zip`。

## 1. 构建环境

| 工具 | 版本要求 | 说明 |
|------|----------|------|
| JDK | 17 | 必须包含 `jlink.exe`、`jar.exe` |
| Maven | 3.9+ | 脚本找不到时自动下载到 `.tools/` |
| Node.js | 18+ | 构建 Vue 前端 |
| Python | 3.9~3.13 | 需能导入项目依赖 |
| .NET Framework | 4.x | 使用系统自带 `csc.exe` 编译启动器 |

Python 依赖：

```powershell
D:\Python\python.exe -m pip install -r python-ems\requirements-build.txt
```

## 2. 执行构建

在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-release.ps1
```

指定 Python 解释器或跳过 Python 服务：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-release.ps1 -PythonExe D:\Python\python.exe
powershell -ExecutionPolicy Bypass -File scripts\build-release.ps1 -SkipPython
```

产物：

```text
dist\EnergyMonitor-v1.1.1-win64.zip
dist\EnergyMonitor-v1.1.1-win64.zip.sha256
```

`-SkipPython` 生成 `*-basic.zip`，不包含预测与 DRO 服务。

## 3. 构建流程

1. `npm run build` 构建前端；
2. `mvn -DskipTests clean package` 打包 Spring Boot；
3. 使用 `jar uf` 将 `frontend/dist` 注入 jar 的 `BOOT-INF/classes/static`；
4. PyInstaller 按 `python-ems.spec` 生成 Python 服务；
5. `jlink` 生成精简 JRE；
6. `csc` 编译 `launcher/EnergyMonitorLauncher.cs`，输出到发行目录根目录；
7. 组装 `build/release/EnergyMonitor/`，压缩并计算 SHA256。

构建脚本会校验压缩包根目录存在 `EnergyMonitor.exe`，避免启动器被放入子目录。

## 4. 发行版设计

- **单端口**：页面与 API 均通过 8082 提供，减少前端跨域和反向代理依赖；
- **H2 文件库**：`jdbc:h2:file:./data/energy_monitor;MODE=MySQL;...`，首次启动执行 `db/h2-schema.sql`，按需写入 `db/h2-data.sql`；
- **双数据库兼容**：分页方言按驱动自动选择，统计 SQL 不使用 MySQL 专有函数；
- **SPA 路由**：`SpaController` 将已知 Vue 路由转发到 `index.html`，避免刷新 404；
- **健康检查**：`/api/health` 免登录，启动器据此判断服务就绪；
- **调度服务自愈**：后端定时轮询 DRO 计划，Python 服务晚启动也能自动恢复；
- **Python 冻结**：`server_entry.py` 直接向 uvicorn 传递 app 对象，避免冻结后字符串导入失败。

## 5. 验证清单

- [ ] 全新目录解压，PATH 中无 Java/Node/Python 也能启动
- [ ] `EnergyMonitor.exe` 位于压缩包根目录
- [ ] `admin / 123456` 登录成功
- [ ] 大屏、设备、安全、历史、策略、告警、报表、用户页面正常
- [ ] WebSocket 实时数据刷新
- [ ] DRO 计划在 Python 服务启动后 30 秒内出现
- [ ] 关闭后重新启动，H2 数据仍然存在
- [ ] 压缩包内不含 `node_modules`、`target`、`.env` 或本地配置

## 6. 常见构建问题

### PyInstaller 报缺少模块

在 `python-ems.spec` 的 `hiddenimports` 中补充，或先确认 `python server_entry.py` 可正常启动。

### jlink 报模块不存在

不同 JDK 的模块名略有差异，可先用 `java --list-modules` 查看；本项目仅依赖标准模块。

### 压缩包过大

- 确认没有将 `python-ems/build`、`node_modules` 打入包内；
- PyInstaller 已排除 tkinter、IPython、pytest 等非运行依赖（matplotlib 因 pyvinecopulib 顶层导入而保留）；
- 完整版约 180~400 MB，基础版约 60~120 MB。
