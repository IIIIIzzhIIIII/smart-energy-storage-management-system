# v1.1.1 发布说明

## 下载

- `EnergyMonitor-v1.1.1-win64.zip`：完整版，内置 JRE、H2 与 Python 预测服务
- `EnergyMonitor-v1.1.1-win64.zip.sha256`：SHA256 校验文件

> 仅支持 Windows 10/11 64 位。目标机器无需安装 Java、MySQL、Node.js 或 Python。

## 启动步骤

1. 从 Releases 下载发行包并完整解压到本地目录（如 `D:\EnergyMonitor`）；
2. 确认 `EnergyMonitor.exe` 位于解压目录根目录；
3. 双击 `EnergyMonitor.exe`；
4. 首次初始化约需 30~90 秒，浏览器会自动打开 `http://127.0.0.1:8082`；
5. 使用 `admin / 123456` 登录。

关闭启动器窗口即停止服务。数据保存在 `data\energy_monitor.mv.db`，迁移时复制整个 `data` 目录。

## 本版内容

- 重构 README 与文档结构，统一采用平台化、专业化的项目表述
- 发行包根目录直接提供 `EnergyMonitor.exe`，构建流程新增根目录校验
- 新增发行版使用、构建与部署文档
- 新增 Windows 桌面启动器：单实例、健康检查、自动打开浏览器、日志目录
- 新增 release 配置：H2 文件数据库、单端口 8082、前端静态资源内置
- 新增 H2 建表与初始化数据
- 新增 `/api/health` 健康检查（免登录）
- 新增 Vue History 路由刷新回退，解决刷新 404
- 数据库兼容改造：分页方言自动识别，统计 SQL 去除 MySQL 专有函数
- 首次启动生成示例历史数据，后续启动自动跳过
- Python 服务支持 PyInstaller 冻结，DRO 计划支持自动重试

## 已知限制

- 发行版默认使用模拟采集，未连接真实串口设备；
- 内置 JWT 密钥仅用于本地运行，部署前必须替换；
- 首次启动生成历史数据较慢，机械硬盘可能需要 1~2 分钟。
