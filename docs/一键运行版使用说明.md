# 一键运行版使用说明

## 1. 系统要求

- Windows 10 / 11，64 位
- 4 GB 以上内存，约 1 GB 可用磁盘空间
- 不需要安装 Java、MySQL、Node.js、Python
- 需要 8082（后端/页面）与 8000（Python 预测）两个本机端口空闲

## 2. 启动步骤

1. 将 `EnergyMonitor-v1.1.0-win64.zip` **完整解压**到本地目录；
   - 建议路径：`D:\EnergyMonitor`
   - 不要直接在压缩包内双击运行
   - 路径尽量不要含中文、空格或特殊符号
2. 双击 `EnergyMonitor.exe`；
3. 首次启动会自动创建 H2 数据库并生成 3 天演示数据，通常需要 30~90 秒；
4. 状态显示“服务已就绪”后会自动打开浏览器，也可手动访问：
   **http://127.0.0.1:8082**
5. 使用内置账号登录：

| 账号 | 密码 | 角色 |
|------|------|------|
| admin | 123456 | 管理员 |
| dispatcher | 123456 | 调度员 |
| user | 123456 | 普通用户 |
| viewer | 123456 | 只读用户 |

> 关闭启动器窗口会同时停止 Java 与 Python 服务。

## 3. 目录说明

```
EnergyMonitor/
├── EnergyMonitor.exe     # 双击启动
├── app/energy-monitor.jar# Java 后端（已内置前端页面）
├── runtime/              # 精简 JRE 17，无需另装 Java
├── python/               # 冻结的 Python 预测/DRO 服务
├── data/                 # H2 数据库文件（重要）
├── logs/                 # 运行日志
├── docs/                 # 文档
└── 使用说明.md
```

## 4. 数据备份与迁移

- 所有业务数据都在 `data\energy_monitor.mv.db`；
- 备份：关闭程序后复制整个 `data` 目录；
- 迁移：把整个 `EnergyMonitor` 目录复制到新电脑，保留 `data` 即可；
- 重置演示数据：关闭程序，删除 `data` 目录，再启动（会重新建库并生成历史数据）。

## 5. 常见问题

### 5.1 双击后没有反应

- 查看是否有安全软件拦截；将程序目录加入白名单；
- 确认解压完整，`runtime\bin\java.exe` 与 `app\energy-monitor.jar` 存在；
- 查看 `logs\backend.log`。

### 5.2 提示端口被占用

```powershell
netstat -ano | findstr :8082
netstat -ano | findstr :8000
```

结束占用进程，或重启电脑后再试。8082 被其他程序占用时，系统无法启动。

### 5.3 页面能打开但 DRO 计划显示获取失败

- Python 服务可能仍在启动，等待 15~30 秒后刷新；
- 查看 `logs\python.log`；
- 若 `python` 目录缺失，系统仍可运行基础功能，但预测/DRO 不可用。

### 5.4 启动超时

- 首次启动生成历史数据较慢，机械硬盘可能需要 1~2 分钟；
- 检查 Windows  defender / 360 是否拦截了 `java.exe` 或 `python-ems.exe`；
- 查看 `logs\backend.log` 中最后一个异常。

### 5.5 想连接真实温湿度传感器

发布版默认 `safety.mode=simulate`（模拟数据），保证没有硬件也能演示。
如需真实串口，请用源码方式启动，并在 `application-release.yml` 中把 `mode` 改为 `real`、配置 `serial-port`。

## 6. 安全说明

- 服务只监听本机回环地址供页面使用，默认不对外网开放；
- 发布版 JWT 密钥为内置演示值，仅适合本地答辩/演示，不要直接用于公网生产环境；
- 如需公网部署，请改用 MySQL、替换 JWT 密钥，并增加 HTTPS 与反向代理。
